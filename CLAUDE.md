# GUÍA PARA CLAUDE LANDING EFIP PARA ESTUDIANTESDIGITALES

Esta es una landing web para Estudiantes Digitales, una plataforma online de venta de cursos orientada a estudiantes de la universidad Siglo XXI en Argentina.

## Edición de estilos
Para editar estilos CSS, *debes* utilizar el archivo `static/styles.css`.

## Edición de contenido
Para editar el contenido de la landing page, *debes* utilizar el archivo `landing.html`.

## Edición de scripts
Para editar los scripts de la landing page, *debes* utilizar el archivo `static/scripts.js`.

## Uso de imágenes
Para utilizar imágenes en la landing page, *debes* extraerlas de `assets/images/`
