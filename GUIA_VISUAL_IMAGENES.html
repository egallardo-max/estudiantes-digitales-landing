📱 Guía: Mejorar Imágenes de Tarjetas en Mobile

Para Bruno - Cómo arreglar imágenes desajustadas en la versión mobile de Estudiantes Digitales

⚠️ Problema Actual

En mobile (375px - 480px), las imágenes de las tarjetas de productos se ven desajustadas o cortadas porque:

  • Las imágenes tienen diferentes proporciones de aspecto
  • El contenedor tiene altura fija (100%)
  • object-fit: cover está cortando partes importantes

✅ Recomendación

Usa OPCIÓN 1 (Cambiar `cover` a `contain`) - Es la más segura, menos invasiva y da los mejores resultados sin afectar el diseño.

OPCIÓN 1: Usar contain (RECOMENDADO) ⭐

Cambiar background-size

EFIP 1 Abogacía
$119.990 ARS

Cambios en el código:

background-size: cover → contain background-repeat: no-repeat; ← AGREGAR

✅ Ventajas

  • Imagen completa, sin cortes
  • Mantiene proporción
  • Cambio simple (1 línea)
  • No afecta otros breakpoints

⚠️ Desventajas

  • Puede haber espacio blanco
  • Imagen más pequeña visualmente
OPCIÓN 2: Aumentar altura

Dar más espacio a la tarjeta

EFIP 1 Abogacía
$119.990 ARS

Cambios en el código:

.course-card { min-height: 140px; → 160px; }

✅ Ventajas

  • Más espacio para imagen
  • Menos cortada con cover
  • Se ve más grande

⚠️ Desventajas

  • Tarjeta más grande
  • Menos cursos visibles
  • Usuario debe scrollear más
OPCIÓN 3: Ampliar imagen

Cambiar proporción imagen/contenido

EFIP
$119.990

Cambios en el código:

.course-card { grid-template-columns: 38% 1fr; → 50% 1fr; }

✅ Ventajas

  • Imagen ocupa 50%
  • Más visible
  • Balance visual

⚠️ Desventajas

  • Contenido se comprime
  • Texto puede cortarse
  • Más radical

🎯 Pasos para Implementar (OPCIÓN 1)

1

Abre landing.html

En tu editor de código (VS Code, Sublime, etc.)

2

Ve a la línea ~770

Presiona Ctrl+G (o Cmd+G en Mac) e ingresa 770

3

Busca @media (max-width: 768px)

Busca la sección de mobile (Ctrl+F)

4

Localiza .course-visual

Dentro de ese media query, busca el bloque .course-visual

5

Cambia background-size

Reemplaza background-size: cover por background-size: contain

6

Agrega background-repeat

Añade una nueva línea: background-repeat: no-repeat;

7

Guarda el archivo

Ctrl+S (o Cmd+S en Mac)

8

Prueba en mobile

Abre en navegador → Presiona F12 → Selecciona vista mobile (375px) → Scrollea a cursos

9

Sube a Hostinger

Via SFTP o File Manager → Sube el archivo landing.html modificado

✅ Checklist Final

Verifica que se cumplan estos puntos:

  • Imagen visible sin cortes en mobile
  • Mantiene proporción (no distorsionada)
  • Se ve bien en 375px, 480px y 768px
  • Contenido de texto no desaparece
  • Botón "Ver detalles" sigue visible
  • Precio se ve correctamente
  • En desktop (1024px+) sigue siendo grid de 3 columnas
